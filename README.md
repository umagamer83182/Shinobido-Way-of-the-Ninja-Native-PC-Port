# Shinobido-Way-of-the-Ninja-Native-PC-Port
Native Windows port of Shinobido: Way of the Ninja (PS2, PAL SCES-53931) built with static recompilation (PS2Recomp). Not an emulator. 60 fps, up to 4K, 21:9, HD texture pack support, F9 settings menu, cheats, skins, mods and controller support. No game data included: bring your own ISO.
